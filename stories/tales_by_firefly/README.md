# Tales by Firefly

*Quiet stories from the Sir Whiskerton universe.*

---

## About

**Tales by Firefly** is a collection of gentle, standalone stories set in the world of Sir Whiskerton's farm. These are the quieter tales — the ones that happen between the adventures, in the small hours, under full moons, on porches and woodpiles and in patches of clover.

They are stories about love that doesn't need to be spoken, guardianship that doesn't need to be seen, and the kind of magic that only exists when no one is watching.
