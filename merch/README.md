# Merchandise

*The guidelines for Sir Whiskerton merchandise.*

---

## Purpose

This folder defines what merchandise is allowed, what requires permission, and what is never permitted.

The Sir Whiskerton Universe is a sanctuary. Its merchandise exists to serve the community, not to exploit it.

## The Categories

| Document | What It Covers |
|----------|---------------|
| **ALLOWED.md** | What fans can make without permission |
| **REQUIRES-PERMISSION.md** | What needs written approval from the Steward |
| **NEVER-ALLOWED.md** | What is never permitted |

## The Short Version

**Allowed for fans (no permission needed):**
- Personal merchandise (for yourself, not for sale)
- Gifts for friends and family
- Educational use in classrooms
- Fan zines sold at cost (not for profit)

**Requires written permission:**
- Any commercial merchandise
- Any crowdfunded project
- Any adaptation (film, game, audio)
- Any use of "Sir Whiskerton" as a brand
- Any AI training
- Any corporate use

**Never allowed:**
- Claiming ownership of the universe
- Creating "official" spin-offs without approval
- Deviating from core themes
- Using the work for hate, violence, or political manipulation

## The Spirit

> *This is not a franchise. It is a legacy. Gifts are meant to be shared, not sold.*
