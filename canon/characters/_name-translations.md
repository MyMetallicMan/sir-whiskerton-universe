 # Character Name Translations

*The English and Chinese names of every character in the Sir Whiskerton Universe.*

---

## Purpose

This file is the master reference for character names in both languages. Every story, translation, adaptation, and fan work should use these names consistently. If a character is not listed here, they are not yet canon.

---
