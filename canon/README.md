# Canon

This folder contains the canonical Sir Whiskerton universe.

Everything here is the source of truth. Stories, characters, artifacts, 
and worldbuilding. Fan works live elsewhere (`/fan-works/`).

## Structure (to be built)

- `/characters/` — Bios for every creature on the farm
- `/artifacts/` — Old Stephen, Old Mable, the Sunken Glade, the Long Road
- `/worldbuilding/` — Themes, quirks, lore, and interaction guidelines
- `/stories/` — The original (raw) versions of the Sir Whiskerton stories
- `/letters/` — Letters from Li Hua

## The First Law

Belonging Without Earning. You do not audition for a place here. You arrive—
scruffy, scarred, or shining—and find the door was already open.

Jingle on.
