# Source Documents

*The raw materials. The scaffolding. The originals.*

---

## Purpose

This folder contains the original PDFs, drafts, and working documents that generated the nine canonical writing-guideline files.

The nine files in the parent folder are the **canonical version** of the guidelines. This folder is the **source material**—the raw materials from which the guidelines were distilled.

---

## Why Preserve Them?

Because they are witnesses. They show the process. They document the choices that were made, the options that were considered, and the reasoning behind the final rules.

They also serve as a safeguard. If the canonical version of a guideline is ever questioned—*"Why is this rule here?"*—the source documents provide the answer.

## A Note on Status

These are **working documents**, not canonical. If a conflict exists between a source document and the canonical guideline, the canonical guideline wins.

The source documents are preserved for reference, not for authority.
