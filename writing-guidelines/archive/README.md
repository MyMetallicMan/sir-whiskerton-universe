## Purpose

This folder contains the raw materials that were used to build the Sir Whiskerton Universe—early attempts at rules, AI conversations, discarded drafts, and fragments that didn't fit anywhere else.

It is not a repository of finished work. It is the *compost*—the fermented layers of thought and iteration that became the golden hum of the farm.
