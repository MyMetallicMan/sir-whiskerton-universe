# Images

*The visual layer of the Sir Whiskerton Universe.*

---

## Purpose

This folder holds the illustrations, diagrams, and visual assets of the universe.

## Structure

| Folder | What It Contains |
|--------|-----------------|
| **/characters/** | Character portraits, reference sheets, and concept art |
| **/scenes/** | Story scenes, splash illustrations, and diagrams |
| **/covers/** | Book covers and title imagery |
| **/artifacts/** | Visuals of the sunken glade, the long road, old stephen, old mable |

## Guidelines

- All images should be in a web-friendly format (JPG, PNG, SVG)
- Naming convention: `character-name_description_v01.png`
- Include a caption or attribution in the file metadata if possible

## The Purpose

The farm is a visual place as much as it is a written one. These images make it real.
