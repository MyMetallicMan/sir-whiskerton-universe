# Character Images

*Portraits, reference sheets, and concept art for the characters of the Sir Whiskerton Universe.*

---

## Purpose

This folder holds the visual references for every character. Portraits, concept art, height charts, expressions, and any other images that help define how a character looks.

---

## Naming Convention

`character-name_description_v01.png`

Example: `sir-whiskerton-portrait_v01.png`

---

## What Belongs Here

- Official portraits
- Character reference sheets
- Concept art
- Expression charts
- Height comparisons
